# Smart Building — Design Brief

สถานะ: อยู่ระหว่างเก็บความต้องการ ยังไม่เริ่มพัฒนาเว็บไซต์

## ข้อสรุปที่ผู้ใช้ยืนยัน

- ผู้ชมหลัก: ลูกค้าองค์กรและผู้บริหาร
- เป้าหมาย: สร้างความประทับใจในช่วงเปิด และทำให้เข้าใจประโยชน์ของ Smart Building ภายในประมาณ 2–3 นาที
- แนวภาพ: โมเดลสถาปัตยกรรมแบบเปิดให้เห็นภายใน ใช้วัสดุและแสงสมจริง
- แสดงข้อมูลประกอบลักษณะ Digital Twin เฉพาะระบบที่กำลังอธิบาย
- มีสองโหมดแยกชัดเจน: ชมตามเรื่องพร้อมมุมกล้องที่จัดไว้ และสำรวจอาคารที่หมุน ซูม เลือกชั้น และคลิกดูระบบได้
- พัฒนาเว็บใหม่แยกจาก designwebpropose โดยใช้ repository smart-building-next

- มี Setup Wizard สำหรับ Product Team / Presale Team เพื่อปรับงานนำเสนอให้ตรงกับลูกค้า
- ระดับการปรับแต่งที่ยืนยัน (Q4): B — ปรับโลโก้ สี ข้อความ ระบบที่แสดงและลำดับเรื่อง รวมถึงปรับจำนวนชั้น ประเภทพื้นที่ และเลือกอุปกรณ์จากรายการที่รองรับ
- อุปกรณ์หลักที่ยืนยัน (Q5): Laptop / Desktop

- ประเภทอาคารรุ่นแรก (Q6): สำนักงาน ประกอบด้วยชั้นสำนักงาน ห้องประชุม Lobby ที่จอดรถ ห้องเครื่อง และดาดฟ้า ให้ความสำคัญกับรายละเอียดโมเดลและแสงก่อนเพิ่มประเภทอาคารอื่น
- การบันทึกและแบ่งปัน (Q7): บันทึกออนไลน์ เปิดต่อข้ามเครื่อง ทีมล็อกอินเพื่อสร้างและแก้ไข ลูกค้าเปิดลิงก์เพื่อชมอย่างเดียว และทีมปิดการแชร์ภายหลังได้ มีส่วนบัญชีผู้ใช้และฐานข้อมูล
- ข้อมูลในฉาก (Q8): ใช้ข้อมูลสาธิตที่สัมพันธ์กันทั้งฉาก เช่น จำนวนคนสัมพันธ์กับพลังงาน และเหตุ Chiller เปลี่ยนสถานะทั้งในอาคารและหน้ารายละเอียด ระบุว่าเป็นข้อมูลจำลอง ตัวเลขผลประหยัดที่นำเสนอเป็นข้ออ้างอิงต้องมีข้อมูลที่ทีมยืนยัน

## ประเด็นที่กำลังพิจารณา — ยังไม่ได้อนุมัติขอบเขต

- รายการระบบ ช่วงจำนวนชั้น และรายละเอียดการปรับพื้นที่
- การแก้ไขฉบับร่างเทียบกับงานที่แชร์ให้ลูกค้าแล้ว
- วิธีล็อกอิน การรับสมาชิกและสิทธิ์การแก้ไขภายในทีม
- รูปแบบแบรนด์เริ่มต้น ภาษา และขอบเขตการรองรับอุปกรณ์รอง
- รายละเอียดสถานการณ์จำลองและเกณฑ์ตรวจฉากสามมิติตัวอย่าง

แนวทางที่กำลังเสนอ: แยกส่วนเตรียมงานนำเสนอออกจากส่วนเปิดให้ลูกค้าดู โดยใช้ประสบการณ์สามมิติและโหมดชมตามเรื่อง/สำรวจอาคารร่วมกัน
